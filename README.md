AI-Based Campus Waste Management System



Project Overview



This project focuses on an AI-based campus waste management system designed to detect waste and support automated waste collection using computer vision, robotics, and embedded systems.



The project is based on our academic final-year project and research paper. Since the original source code is unavailable, this GitHub repository will contain a software reimplementation developed progressively.



Objectives



\- Detect waste objects such as bottles and wrappers.

\- Use computer vision for object detection.

\- Calculate the position of detected waste.

\- Develop robot movement decision logic.

\- Simulate embedded controller operations.

\- Explore autonomous waste collection.



Technologies



\- Python

\- OpenCV

\- YOLOv8

\- Embedded Systems

\- Arduino

\- Robotics
